## 1.0.0

Initial release of Wardrobe.

- Build outfits with snapping image carousels and a larger selected piece.
- Add, remove and reorder layers; move layers with drag handles or up/down buttons.
- Configure image, filter and type properties to match existing clothing notes.
- Assign unclassified items to layers.
- Save image embeds in layer order using the default or a custom Markdown template.
- Choose an outfit destination folder, including nested folders or the vault root.
- Theme-aware interface with responsive layouts and mobile navigation clearance.
- Local operation with no accounts, network requests or telemetry.
